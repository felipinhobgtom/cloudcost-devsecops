Uma estimativa, não uma fatura. Não inclui impostos, descontos, reservas, créditos ou todos os serviços de cloud.

Limites e regra de cálculo
  • Instâncias: inteiro entre 0 e 10.000. Horas por mês: de 0 a 744.
  • Armazenamento e tráfego: até 1.000.000 GB cada. Todos os preços: entre US$ 0 e US$ 1.000 por unidade.
  • Cada categoria é arredondada para centavos; meio centavo arredonda para cima. O total soma as categorias já arredondadas.
  • A API calcula decimais sem ponto flutuante. O navegador envia a representação numérica dos campos; para precisão decimal extensa, use a API diretamente.
  • O JSON aceita no máximo 4.096 bytes. Expoentes científicos devem estar entre -4096 e 4096.
  • Os valores são exemplos, não preços atuais de um provedor. Não há garantia de exatidão de cobrança.
